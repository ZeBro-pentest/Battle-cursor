# 2026-06-26 — Фикс подключения через ngrok

## Что сделано

- Диагностирован баг `ERR_CONNECTION_REFUSED` при попытке логина через ngrok
- Причина: [[frontend/.env]] содержал `VITE_API_URL=http://127.0.0.1:8000/` — фронтенд слал запросы на локальный бэкенд, а не через ngrok
- Исправлено: `VITE_API_URL` в `.env` заменён на `https://matador-radar-demote.ngrok-free.dev/`

## Решения

- В проекте есть два env-файла:
  - `.env` — для локальной разработки (localhost)
  - `.env.ngrok` — для работы через ngrok
- Быстрый способ переключиться на ngrok-режим: либо менять `.env` вручную, либо запускать `npx vite --mode ngrok`
